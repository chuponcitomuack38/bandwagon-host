# 搬瓦工套餐怎么选：从配置、线路到购买步骤

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 品牌。VPS 可以用于学习 Linux、运行个人网站或部署其他服务；选择时，除了看处理器和内存，也要考虑访问者在哪里、使用什么运营商，以及每月需要多少流量。对于刚接触服务器的人，控制面板和付款周期同样值得提前了解。

这份指南整理了参考资料中的常规套餐、线路和购买注意事项，适合比较海外服务器方案的读者。建议先列出用途和预算，再确定资源需求、机房范围及付款周期，最后到对应页面核对当前配置和价格。下文的金额是参考资料列出的未使用优惠码价格，并非对实时库存或报价的保证。

## 看懂配置与线路

### 资源数字分别代表什么

套餐中的 **CPU 核数和内存**关系到服务器能承担的计算任务与同时运行的程序。学习命令、搭建简单网站和运行多个服务，对资源的需求可能不同；选购前应先了解计划安装的软件需要什么资源，而不是只凭核数决定。表中的 1GB 与 2GB 内存、单核与双核，都是比较起点，不代表特定应用一定能顺畅运行。

**SSD 或 NVMe 容量**用于存放系统、程序和数据。可用空间还需要容纳网站文件、数据库及日常增长，不能把标称容量全部当作业务文件的余量。**月流量**则关系到服务器传输的数据量：访问量、页面内容大小和业务用途都会影响消耗，应结合自己的预期留出空间。

**带宽**是网络连接的标称容量，不等于访问者实际能达到的下载速度，也不能单独说明延迟或稳定性。即使两个套餐都标有 2.5Gbps，访问路径、运营商和当时的网络状况也可能不同。比较配置时，要把带宽与流量分开看：前者不是每月可传输的数据总量。

### 线路与机房要一起看

参考资料介绍了几类线路，它们涉及不同运营商或机房，不能仅靠名称判断所有用户的实际体验：

- **CN2 GT**：电信 CN2 的一种线路，参考资料称回程走 CN2，去程可能经过普通骨干网。KVM 套餐的部分机房使用该线路。
- **CN2 GIA**：电信 CN2 线路；参考资料将它列为 CN2 GIA-E、香港和日本大阪套餐所用线路之一。选购时仍需确认具体机房的线路说明。
- **CMIN2**：中国移动精品骨干网，参考资料称 DC6、DC9 已接入。
- **CUP（AS9929）**：联通精品网，参考资料称 DC6、DC9 和 EUNL_1 等机房已接入。
- **大阪软银**：日本大阪机房使用的 SoftBank 线路，是比较日本机房时可以关注的另一选项。

资料将 DC6、DC9 的电信 CN2 GIA、移动 CMIN2 和联通 CUP 组合称为三网优化。这里描述的是相应机房的线路配置，不意味着套餐内所有机房都采用同一组合。先看目标用户主要使用哪家运营商，再确认目标机房的线路，比单纯寻找“最快机房”更有意义；实际路径和访问体验还会随网络情况变化。

还要区分**套餐允许切换到哪些机房**和**某个机房使用什么线路**。例如，一个套餐可切换至大阪，并不意味着它在所有位置都使用大阪软银线路；大阪软银机房也应与下表单列的日本大阪 CN2 GIA 套餐区分。购买前应在目标套餐页面核对可选机房及对应条件。

### 预算有限或正在学习

KVM 入门方案适合先了解 VPS 的基本使用方式，例如学习 Linux 或尝试部署个人网站。它的年付价格在表中较低，但线路和机房选择与 CN2 GIA-E 不同，不能只看相同的 1 核、1GB 内存和 20GB 硬盘就认为两者完全一样。

参考资料列出的 KVM 可选地点包括洛杉矶的 DC2、DC4、DC8，以及弗里蒙特、新泽西、纽约和阿姆斯特丹等。资料另称切换到洛杉矶 DC3 时流量变为原来的三分之一；因此如果计划使用 DC3，应把折减后的额度纳入预算，并在下单前确认当前规则。参考资料也提到 20GB 年付方案可能库存有限，另有季付方案 $27.99/季度起；是否提供及其具体条件需在页面核实。

### 建站时兼顾线路与流量

如果访问者主要在中国内地，除了计算资源，可将目标运营商和机房线路作为比较重点。CN2 GIA-E 标准方案与 KVM 入门配置相同，但参考资料列出的带宽、价格和可切换机房范围不同。资料列出 DC6、DC9、温哥华、大阪软银和荷兰 EUNL_9 等位置；应结合目标访问地区，确认实际想使用的机房是否包含在所选方案中。

同系列大流量方案把月流量从 1TB 提高到 2TB，CPU 和硬盘也有所增加，但内存仍为 1GB。若主要压力来自流量，可以比较两者成本；若应用需要更多内存，则不宜只因为名称中有“大流量”就认定资源全面升级。网站面向海外访问者时，也应考虑访客所在地与机房的关系，而非只按中国内地线路选择。

### 考虑亚太机房

日本大阪和香港方案的价格、资源及月流量差异明显。大阪 CN2 GIA 方案列有 2TB 月流量；香港标准方案为 500GB，香港大流量方案为 1TB，并增加到 2GB 内存。若偏好香港机房，先估算业务流量，再比较两档价格和内存是否符合需要。

参考资料称大阪套餐可切换至大阪、DC6、DC9 和温哥华 CN2 GIA 等机房；香港套餐可切换至香港、新加坡、东京、大阪 CN2 GIA 等机房。切换范围是选购时的灵活性，不是对每个地点访问速度的保证，也不意味着日本和香港方案可以互相替代。具体选择应以业务访问地区、运营商和实际需求为依据。

### 有服务级别要求

CN2 GIA SLA 方案面向需要关注服务可用性条件的用户。参考资料列出 99.99% SLA 在线时间承诺、双路 UPS 和柴油发电机、物理节点双网卡与双路独立光纤路径，以及 100Gbps 上行备用线路；另提到允许 100% CPU 使用率和 7×24 小时 NOC 监控。所列机房为 DC5 SLA。

这些信息适合用于评估基础设施和服务级别，但 SLA 并不等于业务绝对不会中断。选购前应阅读当前服务条款，确认承诺的适用范围及处理方式，并结合自身业务判断是否需要额外的备份和恢复安排。

## 购买与初次使用

以下流程用于整理购买时需要核对的事项，并非特定页面界面的逐项操作说明。

1. **进入对应套餐页面。** 从表中选择与需求相符的入口，核对 CPU、内存、磁盘、月流量和带宽，确认它是想买的标准款或大流量款。不同方案即使名称相近，也可能有不同配置与机房范围。
2. **检查机房和线路。** 确认所需机房是否在套餐允许的范围内，再查看该机房使用的线路及流量条件。特别注意 KVM 的 DC3 流量折减，避免按未折减的额度规划业务。
3. **选择付款周期。** 参考资料中既有月付、季付，也有年付报价。比较时应同时看周期总额、预算和预期使用时间，不要只比较不同周期的单次付款金额；所选套餐实际提供哪些周期，以订单页面为准。
4. **检查订单与优惠。** 付款前核对套餐、周期、金额和可用优惠是否已正确应用。参考资料提到支持支付宝和银联付款，具体付款选项以结算页面显示为准。
5. **完成付款后进入 KiwiVM。** 参考资料介绍，可在控制面板获取 SSH 信息、重装系统和切换机房。初次使用时先查看服务器信息，并根据自己的用途进行系统配置；重装或迁移前应确认相关操作条件及数据安排。

机房迁移的可选范围随套餐而异。即使同属 CN2 GIA 系列，也应先核对自己的方案支持哪些地点；有数据的服务器在变更之前尤其需要规划好备份与恢复，而不是把切换能力当作数据保护方案。

## 下单前检查清单

- **用途与预算**：计划学习、建站还是运行其他服务？能接受的月付、季付或年付总额分别是多少？
- **资源和流量**：软件需要多少内存、磁盘和 CPU？估计的月流量是否在额度内，目标机房是否有流量折减？
- **访问地区与运营商**：主要用户在哪里、使用哪些网络？目标机房的线路是否符合需求？
- **机房范围**：当前套餐能否选择或切换至所需地点？不要把其他套餐的机房列表当作本套餐的选择。
- **订单与售后**：最终价格、付款周期、优惠及退款条件是否已核对？有服务级别要求时，是否已阅读相应条款？

确认这些问题后，再选择适合自己需求的方案。服务器应依法合规使用，并根据业务需要做好数据管理。
